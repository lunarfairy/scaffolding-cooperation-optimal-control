# Figure inputs

Saved aggregate outputs used by the manuscript's Figs. 1–6. Simulation inputs retain the original results; the re-estimated-model comparisons use the pooled-fit analysis. No participant-level records are included.

`human_tie_state_*.csv` contains aggregate analyses of [McKee et al. (2023)](https://doi.org/10.1038/s41562-023-01686-7), using the [OSF dataset](https://osf.io/8ahkg/) under CC BY 4.0. Retain this attribution when reusing the human-data summaries.

After completing the calculations in the main README, `python prepare_figures.py` rebuilds these inputs. `python figures/make_all_figures.py` plots the saved inputs directly.
